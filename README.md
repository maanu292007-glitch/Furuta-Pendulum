# Furuta Pendulum

### Understanding, Building and Controlling an Inverted Pendulum System

## 1. Project Overview

This repository documents my learning and implementation journey with the Furuta Pendulum, a rotary inverted pendulum system.

The project focuses on understanding the mechanical principles, sensor integration, communication protocols and control strategies required to stabilise an inverted pendulum.

## 2. Project Objectives

- Understand the working principle of a Furuta Pendulum.
- Explore IMU sensors and their applications.
- Understand I2C communication.
- Implement sensor integration using Arduino.
- Explore PID control and feedback systems.
- Work towards achieving pendulum stabilisation.
